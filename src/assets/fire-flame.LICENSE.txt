Adaptation: all 64 original frames; premultiplied-alpha
bilinear resampling, vertical orientation for the game's upward Y axis;
52x104 pixels inside each 64x128 tile, packed into 512x1024 RGBA PNG.
The game copies these into its existing particle atlas once at startup.
No Unity runtime or Unity engine code is included.

Reproduce using scripts/prepare-fire-flipbook.ts and the original TGA.
