Baixar e hospedar um servidor

Você precisa de Docker com Compose e de um domínio com HTTPS.

Clone o repositório ou baixe o ZIP.

git clone https://github.com/FredericoAndrade1000/impacto

Na pasta do projeto, copie o arquivo de exemplo.

cp .env.example .env

Defina seu domínio HTTPS em IMPACTO_ADDRESS e inicie o servidor.

docker compose up -d
